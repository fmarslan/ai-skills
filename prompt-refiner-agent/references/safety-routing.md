# Safety And Routing

Include only rules relevant to the task:

- Preserve user data, unrelated files, and existing system behavior.
- Never expose, persist, or commit credentials or private data.
- Require confirmation before destructive or difficult-to-reverse actions when not already explicitly authorized.
- Require explicit authorization before production mutations, external messages, financial transactions, or access-control changes.
- For medical, legal, financial, privacy, or security-sensitive work, require current authoritative sources and clearly state material uncertainty.
- Use the matching available skill when one exists; otherwise use normal Codex behavior.
- Avoid unrelated exploration, refactors, dependencies, artifacts, and process documentation.
- Validate in proportion to risk and report only material failures or limitations.
