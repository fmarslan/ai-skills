# Project Name

This project uses a Docker Compose based Dev Container for local development.

## Development

Open the repository in VS Code and choose `Dev Containers: Reopen in Container`.

See `docs/DEVELOPMENT.md` for setup, commands, debugging, and local service details.

Stack-specific code, package manifests, lockfiles, and build/test configuration live under `src/`.

## Environment

Copy values from `.env.example` into your local environment manager or a local `.env` file when the selected stack requires one. Do not commit `.env`.

See `docs/ENVIRONMENT.md` for the full variable contract.
